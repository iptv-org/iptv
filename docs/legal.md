# Legal and Usage Guide

This repository is intended to organize and maintain publicly available IPTV links and lawful personal use.

## Do not add

- pirated streams
- unauthorized re-broadcasts
- streams without clear legal availability
- private or paid channels shared without permission

## Recommended use

- only use content you are legally allowed to access
- verify source legitimacy before adding a stream
- avoid redistributing content that is not clearly authorized

## Responsibility

Maintainers and contributors are responsible for ensuring the material they add does not violate copyright or distribution rules.

## Practical rule

If you are unsure whether a stream is legally allowed to be shared, do not add it.

## If a source is broken or removed

- remove the entry from the playlist
- document if needed in a changelog or PR description
- avoid re-adding the same broken link without verification

## Summary

This repo should be kept lawful, organized, and useful for legitimate IPTV curation. Quality and legality matter more than raw quantity.
